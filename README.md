# فصيح (Fasih)

تطبيق أندرويد (دروسه ومراجعاته تعمل بلا إنترنت) لنقل متعلم عربي من مستوى A2 إلى C1 في الإنجليزية (IELTS Academic 7.0+) خلال 18 شهراً، مع مصطلحات القانون ومكافحة الفساد والذكاء الاصطناعي والبحث العلمي.

- `www/` تطبيق الويب (المحرك والواجهة والمحتوى): يعمل أيضاً بفتح `www/index.html` في متصفح الحاسوب.
- `android/` غلاف أندرويد (WebView + تنبيهات + نطق + تعرف على الكلام + تسجيل).
- `content/raw/` المحتوى الأصلي بصيغة JSON، و`tools/build_content.py` يحوّله إلى `www/content/*.js`.
- `tools/validate.py` فحص بنية المحتوى، `tools/test_web.py` و`tools/sim.py` اختبارات آلية للواجهة ومحاكاة متعلم.
- `SPEC.md` مواصفات المحتوى، `research/` خلاصة البحث العلمي وحقائق IELTS مع المصادر.

## المعلّم (الذكاء الاصطناعي)
تبويب «المعلّم» يصل التطبيق بـ Claude أو ChatGPT أو Gemini أو Grok بطريقتين:

- **الاشتراك العادي (بلا API):** يجهّز فصيح الطلب (مستوى المتعلم، نقاط ضعفه، ما يريده، وصيغة «حزمة فصيح») ويفتح به تطبيق الذكاء، مع صورة تُلتقط داخل فصيح إن وُجدت. يعود الرد إلى فصيح بلصق «الحزمة» أو مشاركتها.
- **مفتاح API:** محادثة داخل فصيح (نص وصور وردود متدفقة). المفتاح يُكتب في نافذة أندرويد خارج صفحة الويب، ويُشفَّر بـ Android Keystore، ولا يُرسل إلا إلى الشركة صاحبته.

التطبيق يستقبل أيضاً ما يُشارَك إليه من تطبيقات أخرى: نص فيه حزمة، كلمة محددة، أو صورة تُرفق بطلب «اشرح صورة».

«حزمة فصيح» هي JSON يضيف كلمات ودروساً ونصوص قراءة وتمارين وأخطاء المتعلم، ويقترح تعديل إعدادات الخطة. كل حزمة تُفحص (قائمة بيضاء للحقول وحدود للأحجام) وتُعرض للموافقة قبل تطبيقها، ويمكن حذفها لاحقاً.

- `www/js/tutor.js` الطلبات والبرومبتات والحزم ودفتر الأخطاء، `www/js/chat.js` المحادثة ومحوّلات الشركات الأربع، `android/.../AiBridge.java` المشاركة والصور والمفاتيح والاتصال.
- صفحة الويب محجوبة عن الشبكة (CSP في `index.html` و`MainActivity.Client`)؛ الاتصال الوحيد يتم من `AiBridge` إلى أربعة عناوين ثابتة.
- المواصفات: `TUTOR_SPEC.md` و`CHAT_SPEC.md`. الاختبارات: `tools/test_tutor.py` و`tools/test_chat.py` و`tools/test_integration.py`، واختبارات المحاكي في `test/run.mjs`.

## البناء
الدفع إلى الفرع `fasih-src` يبني APK غير موقّع عبر GitHub Actions وينشره في الفرع `fasih-build`. التوقيع يتم خارج GitHub بمفتاح محفوظ على حاسوب صاحب التطبيق (مجلد `keystore/`، غير منشور).

All learning content is original. No real exam material is included.
