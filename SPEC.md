# FASIH content spec v1
App "Fasih": offline Android app taking an Arabic-speaking adult (Algerian, master's student in transparency/anti-corruption, future legal-AI researcher) from English A2 to C1 and IELTS Academic 7+. He memorises slowly, so examples must be vivid, concrete and easy to picture.

## Global rules (all kinds)
- Output files: UTF-8 JSON, each file = ONE JSON array of objects. No comments, no trailing commas, no markdown fences. Escape inner double quotes.
- Everything must be ORIGINAL, written by you now. Never copy sentences, passages, questions or lists from books, websites, dictionaries or real exams. No real past IELTS questions.
- British spelling. Natural, correct, modern English. Arabic = clear Modern Standard Arabic (فصحى مبسطة), no dialect, no transliteration.
- Neutral, respectful content. No alcohol, dating, gambling, pork, politics-of-the-day or religious debate. Good topics: study, work, science, technology, health, environment, cities, travel, law, justice, transparency, public service, history, sport.
- Keep each file small: write it with the Write tool in chunks (max ~80 vocab items, or ~5 grammar units, or ~5 reading texts per file). Use the exact file names given in your task.
- After writing EACH file run: `python3 /home/claude/fasih/tools/validate.py <kind> <file>` and fix every error until it prints OK.
- Your final reply: only the list of files written with item counts (max 6 lines). Do not paste content.

## Exercise objects (used inside several kinds). Key "k" = type
- mc: {"k":"mc","q":"She ___ to work by bus every day.","o":["go","goes","is going"],"a":1,"why":"تفسير قصير بالعربية"}  (3-4 options, exactly one correct, a = index from 0; vary the position of the correct answer)
- gap: {"k":"gap","q":"I ___ (not/see) him since Monday.","a":["haven't seen","have not seen"],"why":"…"}  (q contains ___ ; a = ALL acceptable answers; answer max 4 words)
- fix: {"k":"fix","q":"He don't like coffee.","bad":"don't","good":["doesn't","does not"],"why":"…"}  (sentence with exactly ONE error; bad = the exact wrong word(s) as written in q; good = accepted replacements)
- order: {"k":"order","a":"I have never been to London.","ar":"لم أذهب إلى لندن قط."}  (the app shuffles the words; 5-12 words; only one natural order)
- trans: {"k":"trans","q":"People say that he is very rich.","start":"He is said","a":["He is said to be very rich."],"why":"…"}  (rewrite beginning with start; every answer begins with start)
- tfng: {"k":"tfng","q":"statement","a":"T","why":"…"}  (a = "T", "F" or "NG")
- head: {"k":"head","para":2,"o":["heading A","heading B","heading C","heading D"],"a":0}  (choose the best heading for paragraph index para, counted from 0)
"why" is a SHORT explanation in Arabic (max 25 words), required for mc, gap, fix, trans, tfng.

- No duplicates (same w and p). No rare, archaic or offensive words. No proper names.
